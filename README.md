## ✨ Features
- **Rich Text Editing** - Full RTF support with formatting options
- **Auto-Save** - Never lose your work - automatic session recovery
- **File Operations** - New, Open, Save, Save As with .txt and .rtf support
- **Smart Defaults** - Defaults to plain text (.txt) for everyday use
- **Lists & Formatting** - Bullet lists, numbered lists, and checkboxes
- **Undo/Redo** - Full editing history with Ctrl+Z and Ctrl+Y
- **Zoom Controls** - Ctrl+Scroll or menu options to zoom in/out
- **Modern UI** - Dark theme with smooth rounded corners
- **Keyboard Shortcuts** - Ctrl+S (Save), Ctrl+Shift+S (Save As)
- **No Clutter** - Clean interface without scrollbars or distractions
## 🚀 Installation
### Using the Installer
1. Download `Noted-Setup.exe` from the releases
2. Run the installer
3. Choose whether to set Noted as your default text editor
4. Launch Noted from Start Menu or Desktop
### Requirements
- Windows 10 or later
- .NET 9.0 Runtime
## 🎨 Interface
- **Title Bar** - Custom chrome with File, Edit, and View menus
- **Editor** - Distraction-free editing area
- **Status Bar** - Shows line and column position
## ⌨️ Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New File |
| `Ctrl+O` | Open File |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+Scroll` | Zoom In/Out |
