## ✨ Features
### Core Functionality
- **Rich Text Editing** - Full RTF support with formatting options
- **Smart File Operations** - New, Open, Save, Save As with multi-format support (.txt, .rtf, .log, .md, and more)
- **File Association** - Open files directly from Windows Explorer with "Open With" or set as default editor
- **Command-Line Support** - Launch with file path argument to open files instantly
- **Smart Defaults** - Defaults to plain text (.txt) for everyday use
### Editing Features
- **Lists & Formatting**:
  - Bullet Lists - Professional bullet point formatting
  - Numbered Lists - Automatic sequential numbering
  - Checklists - Interactive checkboxes (☐/☑)
- **Undo/Redo** - Full editing history with Ctrl+Z and Ctrl+Y
- **Zoom Controls** - Ctrl+Scroll or menu options to zoom in/out
- **Auto-Focus** - Start typing immediately on launch
### User Experience
- **Modern Dark UI** - Sleek dark theme with smooth animations
- **Custom Dialogs** - Beautiful themed confirmation dialogs
- **Visual Feedback** - Notification pills for file operations (3s fade animation)
- **Smart Prompts** - Automatic save prompts when closing with unsaved changes
- **Exit Confirmation** - Never lose work with exit save reminders
- **No Clutter** - Minimalist interface focused on your content
### Performance & Reliability
- **Stable Architecture** - Optimized single-document interface
- **Debounced Updates** - Smooth editing without lag or crashes
- **Enhanced Error Handling** - Robust file operations with clear feedback
## 🚀 Installation
### Using the Installer
1. Download `Noted-Setup.exe` from the releases
2. Run the installer
3. Choose whether to set Noted as your default text editor
4. Launch Noted from Start Menu or Desktop
### Requirements
- Windows 10 or later
- .NET 9.0 Runtime
## 🎨 Interface
- **Title Bar** - Custom chrome with File, Edit, and View menus
- **Editor** - Distraction-free editing area with instant focus

## ⌨️ Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New File |
| `Ctrl+O` | Open File |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+Scroll` | Zoom In/Out |
## 🔧 Technology Stack
- **Framework**: .NET 9.0
- **UI**: WPF (Windows Presentation Foundation)
- **Architecture**: MVVM Pattern
- **Installer**: NSIS
## 📋 Supported File Types
Noted can open and edit a wide variety of text-based files:
- Text: `.txt`, `.log`, `.md`
- Rich Text: `.rtf`
- Web: `.html`, `.css`, `.xml`, `.json`
- Code: `.js`, `.ts`, `.py`, `.java`, `.c`, `.cpp`, `.cs`, `.php`, `.rb`, `.go`, `.rs`
- Scripts: `.sh`, `.bat`, `.ps1`, `.sql`
- Config: `.ini`, `.cfg`, `.conf`
